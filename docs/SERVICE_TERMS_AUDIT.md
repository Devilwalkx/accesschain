# Service terms audit (geocoding, routing, mapping)

Date of reading: 2026-10-17. Method: the manual GitHub Actions workflow `probe-service-terms` (`.github/workflows/probe-terms.yml`) fetched each page from a GitHub runner and printed it into the job log (runs 39049563392 and 39049695305 on branch `claude/h-gm8m50`). The sandbox that built the app cannot reach these sites, so the clauses below were read from those logs. This is a technical reading, not legal advice. Policies "may change without notice" (both services say so): re-run the probe before any wider release.

## What the app really calls

| Purpose | Service | Exact endpoint | When | Sent |
|---|---|---|---|---|
| Find the place (geocoding) | OpenStreetMap **Nominatim** (public server) | `GET https://nominatim.openstreetmap.org/search?q=<fixed place name>&format=jsonv2&extratags=1&limit=3&viewbox=…&bounded=1` | once per place per 30 minutes, only after the person chose a place | one of 10 fixed place names ("Tate Modern"…); never anything the person typed |
| Journey routing | **TfL Unified API** | `GET https://api.tfl.gov.uk/Journey/JourneyResults/{from}/to/{lat,lon}?accessibilityPreference=StepFreeToVehicle,StepFreeToPlatform&walkingSpeed=Slow` | per "Plan"/"Check again" tap | start (station id, rounded location, or a typed UK postcode) and the place's coordinates |
| Lift outages | **TfL Unified API** | `GET https://api.tfl.gov.uk/Disruptions/Lifts/v2` | same moment | nothing |
| Map tiles | none. **There is no map** (map not built) | | | |
| OSM editing API (`api.openstreetmap.org`) | **not used any more** (see below) | | | |

The needs profile is never sent. No API key is bundled.

## OpenStreetMap Foundation: API Usage Policy (the editing API)
Source: https://operations.osmfoundation.org/policies/api/ (HTTP 200).
Clause: "The editing API is provided in order to edit the map data, not for read-only purposes or projects."
Finding: the previous build (commit 8907428) read each place's last-edit date from `api.openstreetmap.org/api/0.6/<type>/<id>.json` on Android. That is read-only use of the editing API. **Change made:** `allowOsmApi` is `false` on every platform; the app no longer calls it (end-to-end test asserts no request to that host). Consequence: place notes count as evidence only if the OSM object carries a `check_date`; otherwise they are shown with "No date available" and not counted. If edit dates are wanted later, use a read-only source whose own policy permits it (for example Overpass, whose policy has not been read) or a self-hosted extract.
The same page requires "Valid User-Agent identifying application and version" and "Clearly display licence attribution": see above.

## OpenStreetMap Foundation: Tile Usage Policy
Source: https://operations.osmfoundation.org/policies/tiles/ (HTTP 200). Not applicable: **the app shows no map and requests no tiles.** If a map is added later the policy requires, among other things: the exact URL `https://tile.openstreetmap.org/{z}/{x}/{y}.png`; visible attribution; a User-Agent that identifies the app; honouring cache headers (or at least 7 days); and it forbids bulk download, prefetch and offline use ("Offline use is not permitted on tile.openstreetmap.org").

## OpenStreetMap licence and attribution
Sources: https://www.openstreetmap.org/copyright and https://osmfoundation.org/wiki/Licence/Attribution_Guidelines (both HTTP 200).
- "Where you use OpenStreetMap data, you are required to do the following two things: Provide credit to OpenStreetMap by displaying our attribution notice. Make clear that the data is available under the Open Database License."
- Guidelines: "Attribution must be to “OpenStreetMap”… The historical forms of attribution “© OpenStreetMap contributors” or “© OpenStreetMap” are acceptable." For geocoding: "Applications that incorporate such a geocoder must credit OpenStreetMap." "There needs to be a way to access more information, including origin and licence of the data… (for example by making the text a clickable link)."
- The app uses the first form on the result screen next to the place information, plus a button that opens the copyright page. Changed in this pass: a real link (previously only plain text).
- ODbL share-alike: the app does not store or redistribute OSM data (it is fetched live and shown); an extract is not bundled.

## Changes made because of this audit
1. Stopped calling `api.openstreetmap.org` (read-only use of the editing API). Edit dates are no longer used.
2. Nominatim: at most one request per 1.1 s; 30-minute cache; 10-minute cache for "no match"; identical simultaneous requests merged; no repeat of a query on retry.
3. Native User-Agent now names the application id, the version and the project URL.
4. Added the TfL Ordnance Survey attribution and a non-endorsement line; made the OpenStreetMap attribution a tappable link.
5. Typed start places go to TfL only, as a validated UK postcode; never to OpenStreetMap, never as free text, never as search-as-you-type.

## Open owner decisions (not solved by code)
- Public Nominatim: keep, or put a small proxy/cache in front of it so the service can be switched without an app update and the traffic of all users is shared and cached? (The policy requires switchability; the LLM clause requires a deliberate decision.)
- TfL: register an application and decide how a key would be protected, or keep anonymous use and ask TfL.
- Someone should read TfL's branding guidelines and the current live licence page in a normal browser.
- Edit dates for community notes need a permitted read-only source.
