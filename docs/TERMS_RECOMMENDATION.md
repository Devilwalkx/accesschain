# AccessChain: the unresolved service-terms clauses, what the app does today, and one recommended fix for each

Source: `docs/SERVICE_TERMS_AUDIT.md` (clauses quoted there were read from the services' own pages by a CI job on 2026-10-17). This is a technical reading, not legal advice, and the policies can change without notice. Status words: **Met** (the app's behaviour meets the clause as read), **Not met**, **Unknown** (could not be read or decided).

| # | Clause (source) | What the app does today | Status | Recommended technical remedy | Who must act |
|---|---|---|---|---|---|
| 1 | Nominatim usage policy: "Apps must make sure that they can switch the service at our request at any time (in particular, switching should be possible without requiring a software update). If at all possible, set up a proxy and also enable caching of requests." | Calls `https://nominatim.openstreetmap.org/search` directly from the phone, once per chosen place per 30 minutes, with an identifying User-Agent, at most 1 request per 1.1 s, in-memory cache. The address is a constant in the app. | **Not met** (no switch, no proxy) | **Stop calling Nominatim from the app.** The app offers only 10 fixed places. Replace the runtime lookup with a small table shipped in the app: place name, coordinates and OSM id, resolved once by a person with Nominatim's website or the OSM map, dated, with the OpenStreetMap attribution and ODbL link kept on screen. This removes the clause, the traffic and the User-Agent question. Place notes (the community facts) would be refreshed by a manual script run by the owner, not by every phone. Cost: about half a day; no ongoing cost. | Me (code); you confirm the 10 places and whether you accept extracting ten coordinates under ODbL (attribution kept) |
| 2 | Nominatim policy, AI clause: the public API must not be built in by assistants "as a generic geocoding... service"; use is allowed only where the developer made "a deliberate, informed decision". | A fixed list of ten names, no free-text search. The code was written with an AI assistant. | **Unknown** | Falls away with remedy 1 (no public Nominatim use remains). | none after remedy 1 |
| 3 | TfL Transport Data Service licence (read from an archived copy; the live page returned a bot check): the licence "shall apply from the date of registration"; TfL recommends registering an application and sending an `app_key`; 500 calls per minute per feed. | Calls `api.tfl.gov.uk` anonymously, no key, two calls per trip, "Powered by TfL Open Data" and the Ordnance Survey attribution shown, no TfL logo. | **Unknown** (anonymous use is not described as covered) | **Register an app at TfL's API portal in your own name and put the key in the app for the pilot** (the pilot has a handful of testers, far below 500 calls per minute). A key inside an APK can be extracted; for the pilot that is an accepted, revocable risk. Before any wider release move the calls behind a small proxy that holds the key and caches answers for a few minutes (this is the same small server as ScopeLock's hosting option A and adds no new vendor). | You (registration, 10 minutes); me (config field + proxy later) |
| 4 | TfL "design and branding guidelines" referenced by the licence | No TfL logo, roundel or colours are used; text attribution only. | **Unknown** (guidelines not read) | Keep text-only attribution. You (or a person) read the guidelines page once in a normal browser before any logo or TfL-like styling is added. | You |
| 5 | OSM attribution (ODbL, "© OpenStreetMap contributors" with a link to the licence) | Shown on every result screen and in Privacy; the link opens the OpenStreetMap copyright page. | **Met** | none | none |

**Concrete recommendation in one sentence:** replace the live Nominatim lookup with a dated, attributed table of the ten places (remedy 1), register a TfL application key for the pilot (remedy 3), and defer the proxy until more than a handful of people use the app. **Not done yet:** none of this is implemented; it needs your confirmation of remedy 1 and the TfL registration.
